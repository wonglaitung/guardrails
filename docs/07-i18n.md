# 07 - 多语言支持（简繁体）

## 概述

项目支持中文简体、繁体、英文及中英混合文本的自动识别与处理，通过语言检测自动选择对应的占位符。

## 语言检测机制

### 检测策略

`UniversalPIIGuardrail` 通过以下策略检测文本语言：

1. **字符统计**: 统计繁简特有字符数量
2. **关键词检测**: 当字符数相近时检查特定词组
3. **英文检测**: 无中文字符时判定为英文

```python
def _detect_script(self, text: str) -> str:
    """
    检测文本脚本类型
    
    Returns:
        "simplified", "traditional", 或 "english"
    """
```

### 繁简特有字符

```python
# 繁体中文特有字符
traditional_chars = set(
    '們個時說國過這裡學經動點話書電車頭長問體機開樣東聽聲請義見間實氣報給起錢東邊變還'
    '電話號碼證字聯絡信箱伺服器位址護照統社會信用代碼車輛號牌...'
)

# 简体中文特有字符
simplified_chars = set(
    '们个时说国过这里学经动点话书电车头长问体机开样东听声请义见间实气报给起钱东边变还'
    '电话号码证字联络信箱服务器地址护照统社会信用代码车辆号牌...'
)
```

### 检测流程

```python
tc_count = 0  # 繁体字符数
sc_count = 0  # 简体字符数
cn_count = 0  # 中文字符数
en_count = 0  # 英文字符数

for char in text:
    if '\u4e00' <= char <= '\u9fff':  # Unicode 中文字符范围
        cn_count += 1
        if char in traditional_chars:
            tc_count += 1
        elif char in simplified_chars:
            sc_count += 1
    elif 'a' <= char.lower() <= 'z':
        en_count += 1

# 判断逻辑
if cn_count == 0:
    return "english"

if tc_count > sc_count:
    return "traditional"
elif sc_count > tc_count:
    return "simplified"
else:
    # 检查特定关键词
    for kw in traditional_keywords:
        if kw in text:
            return "traditional"
    return "simplified"
```

class ChinesePIIGuardrail:

        # 根据字体类型选择占位符

## 使用方式

### 手动指定语言

```python
from chinese_guardrail import ChinesePIIGuardrail

# 简体中文模式
guardrail_sc = ChinesePIIGuardrail(script_type="simplified")
safe_text = guardrail_sc.redact("我的手机号是13812345678")
# 输出: "我的手机号是<手机号>"

# 繁体中文模式
guardrail_tc = ChinesePIIGuardrail(script_type="traditional")
safe_text = guardrail_tc.redact("手機號是13812345678")
# 输出: "手機號是<手機號>"
```

### 自动检测语言

```python
from chinese_guardrail import UniversalPIIGuardrail

guardrail = UniversalPIIGuardrail()

# 自动识别简体
safe_text = guardrail.redact("我的手机号是13812345678")
# 输出: "我的手机号是<手机号>"

# 自动识别繁体
safe_text = guardrail.redact("手機號是13812345678")
# 输出: "手機號是<手機號>"

# 自动识别英文
safe_text = guardrail.redact("My phone is 13812345678")
# 输出: "My phone is <PHONE>"
```

### 快捷函数

```python
from chinese_guardrail import redact_pii, redact_pii_traditional, mask_pii

# 简体快捷函数
safe_text = redact_pii("身份证：110101199001011234")

```

## 注意事项

### 正则表达式不区分繁简

PII 格式（手机号、身份证等）在简繁体中相同：

```python
# 手机号正则：适用于简繁体
regex = r"(?<!\d)(1[3-9]\d{9})(?!\d)"

# 身份证正则：适用于简繁体
regex = r"(?<!\d)([1-9]\d{5}...)(?!\d)"
```

### 差异只在占位符和上下文

- **占位符**: 简体 `<手机号>` vs 繁体 `<手機號>`
- **上下文关键词**: 简体 "手机" vs 繁体 "手機"

### 特殊情况

```python
# 部分词汇简繁相同
"身份证" vs "身份證"  # 有差异
"护照" vs "護照"     # 有差异
"邮箱" vs "信箱"     # 完全不同（台湾用 "信箱"）
```
